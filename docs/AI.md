# AI

## Состояния
`patrol → search → chase → return`

- **patrol**: случайная точка вокруг `hx,hy`, ожидание 1–3 с
- **search**: идёт к шуму/последней позиции, крутится, теряет след через 3 с
- **chase**: видит игрока — стреляет с задержкой, держит дистанцию
- **return**: возврат домой после потери цели

## Восприятие
- `det` — дистанция обнаружения (модифицируется погодой и фонарём)
- `los()` — линия видимости сквозь стены
- Слух: `p.noise` от шагов (150) и выстрела (560)

## Двери
- `doorPass(x,y,r,wall)` — коридор 27 px от центра южной стены
- Игрок входит/выходит автоматически, пересекая порог
- Враг идёт к точке чуть ниже двери → затем внутрь
- Внутри дома стены этого дома для врага игнорируются, `los` не режет

## Спец-поведение
- `charge` (барсук, рысь): рывок 0.6 с на 340 px/s при `d < 330`
- `leader` (вожак): при агре зовёт стаю в радиусе 700
- `sniper` (ястреб): лазерный прицел перед выстрелом
- `gas` (скунс): газовое облако 6 с
- `flee` (заяц): бежит от игрока, не стреляет
- `pounce` (рысь): как charge, но слабее
