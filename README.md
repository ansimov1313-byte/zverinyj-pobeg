# Звериный Побег

Изометрический экстракшн-рогалик про лиса в духе Fallout 2 / Tarkov.
Чистый HTML5 Canvas + JS, без внешних библиотек, работает офлайн.

## Играть
https://ansimov1313-byte.github.io/zverinyj-pobeg/

## Управление
- Левая половина экрана — джойстик движения
- Правая половина — прицел/огонь
- Кнопки внизу справа — перезарядка, рюкзак, фонарь, аптечка, действие
- Клавиатура: WASD — движение, мышь — прицел, ЛКМ — огонь, R — перезарядка, F — фонарь, E — действие, I/Tab — рюкзак

## Механики
- Процедурная карта с домами, дорогами, зонами и тайниками
- Эвакуация: основной выход + платные точки (лодка, паром, вертолёт) + тайный лаз
- Риск-система: уйти с добычей или рискнуть за ×1,4
- Сюжетная линия Бориса (5 этапов) и контракты Сыча
- Нора: постройки, мастерская, улучшения снаряжения
- 11 видов зверей (крыса, кот, волк, кабан, медведь, ястреб, скунс, барсук, вожак, заяц, рысь)
